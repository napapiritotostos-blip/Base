# Готово: как подключить Hoplite к VS Code

Расширение **Hoplite Agent** лежит в этом репозитории. Оно подключается к Hoplite по API и позволяет работать с агентом прямо в VS Code: ставить задачи, выбирать модель и параметры запуска, следить за ходом работы. Ниже — сборка, установка и подключение.

## Что понадобится

- VS Code версии 1.90 или новее.
- Node.js 22.18 или новее, npm и Git — только чтобы собрать расширение.
- Учётная запись Hoplite, в которой есть хотя бы один проект.

## 1. Получите API-ключ Hoplite

1. Откройте [app.hoplite.sh](https://app.hoplite.sh/) и выберите нужный воркспейс.
2. Перейдите в **Settings → Workspace → API keys** и создайте ключ.
3. Скопируйте ключ. Он начинается с `hop_` и показывается один раз.

Личный ключ действует с правами вашей учётной записи. Если вы создаёте сервисный аккаунт (**API keys → Service accounts → New service account**), задайте ему права: **Projects — Read**, **Threads — Write**, **Model keys — Read**.

## 2. Соберите расширение

```bash
git clone https://github.com/napapiritotostos-blip/Base.git
cd Base
npm ci
npm run package
```

В папке появится файл `hoplite-vscode-0.1.0.vsix`.

## 3. Установите его в VS Code

Из терминала:

```bash
code --install-extension hoplite-vscode-0.1.0.vsix
```

Или в самом VS Code: откройте **Extensions** (`Ctrl+Shift+X`), нажмите `…` в заголовке панели, выберите **Install from VSIX…** и укажите файл.

## 4. Подключите расширение к Hoplite

1. Нажмите значок Hoplite на панели действий слева (круг с буквой «Λ»).
2. В разделе **Chat** нажмите **Set API Key** и вставьте ключ. То же самое делает команда **Hoplite: Set API Key** из палитры (`Ctrl+Shift+P`). Расширение проверит ключ и сохранит его в защищённом хранилище VS Code.
3. Выберите проект. Если открытая папка — клон репозитория, привязанного ровно к одному проекту Hoplite, проект выберется сам. Иначе нажмите **Select Project**.

Подключение работает, если над полем ввода появился список моделей, а в разделе **Threads** — треды проекта.

## 5. Работайте с агентом

- **Новая задача.** Опишите её в поле ввода и нажмите **Start thread** (или `Enter`).
- **Модель и параметры.** Над полем ввода выбираются модель, **Reasoning** и **Speed**. Кнопка ⚙ открывает остальное: название треда, лимит расходов в долларах, автослияние pull request, репозитории и базовые ветки. Те же параметры есть в настройках VS Code (`hoplite.*`) и в командах **Hoplite: Select Model**, **Select Reasoning Effort**, **Select Speed**.
- **Ход работы.** Ответ агента, вызовы инструментов и статус появляются в чате по мере выполнения. Кнопка **Stop** останавливает запуск.
- **Продолжение.** Напишите ответ в открытом треде. Для следующих сообщений можно выбрать другую модель.
- **Треды.** Раздел **Threads** показывает треды проекта. Щелчок открывает тред, правая кнопка — diff, pull request, переименование, лимит расходов, архив.
- **Код из редактора.** Выделите фрагмент, откройте контекстное меню и выберите **Add Selection to Hoplite Chat**.

Агент работает в облаке Hoplite с репозиторием проекта на GitHub. Локальные незакоммиченные изменения он не видит.

Reasoning, speed, автослияние и репозитории задаются при создании треда. В открытом треде меняются модель и лимит расходов. Полный список параметров, команд и ограничений — в [README.md](README.md).

## Если что-то не работает

| Что видно | Что сделать |
| --- | --- |
| «The API key is missing, invalid, or lacks the permission…» | Ключ неверный, отозван или ему не хватает прав. Создайте новый и выполните **Hoplite: Set API Key**. |
| В списке моделей только «Default» | У ключа нет права `modelKey:read` (Model keys — Read). |
| Нет проектов для выбора | У ключа нет доступа к проектам, или в воркспейсе ещё нет проекта. Создайте проект в Hoplite. |
| Жёлтая точка в заголовке чата | Поток событий недоступен, расширение опрашивает API. Обновления приходят с задержкой в несколько секунд. |
| Нужен другой адрес API | Задайте `hoplite.apiBaseUrl` в настройках пользователя. Требуется HTTPS. |
| Нужны подробности ошибки | Откройте журнал командой **Hoplite: Show Log**. |

## Что проверено

- 32 автотеста: клиент API, разбор потока событий, состояние треда, сборка параметров запуска.
- Сборка `.vsix`.
- Запуск в VS Code 1.145.2 с локальным мок-сервером по OpenAPI-спецификации Hoplite: автовыбор проекта, создание треда с выбранными моделью и параметрами, ответ в реальном времени, продолжение треда со сменой модели.

С реальной учётной записью Hoplite расширение не проверялось: в среде сборки не было API-ключа. Если при первом подключении что-то пойдёт не так, пришлите текст ошибки из журнала.
