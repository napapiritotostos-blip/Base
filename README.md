# Hoplite Agent для VS Code

Расширение подключает VS Code к облачному кодинг-агенту [Hoplite](https://hoplite.sh) через его публичный API: вы ставите задачи, выбираете модель и параметры запуска и следите за работой агента, не выходя из редактора.

Это не официальный продукт Hoplite. Расширение использует только документированный API (`https://api.hoplite.sh`, [OpenAPI](https://hoplite.sh/openapi.json)).

Пошаговая инструкция по подключению — в [done.md](done.md).

## Возможности

- **Чат с агентом** в боковой панели: новый тред или продолжение существующего. Ответ приходит в реальном времени через поток событий (`GET /api/events/stream`); если поток недоступен, расширение переходит на опрос.
- **Список тредов** выбранного проекта со статусами. Из списка тред можно открыть, переименовать, архивировать, задать ему лимит расходов, посмотреть diff и открыть pull request.
- **Выбор модели и параметров запуска** прямо над полем ввода (см. таблицу ниже). Список моделей и поддерживаемые ими уровни reasoning и скорости берутся из `GET /api/model-providers`.
- **Управление запуском**: Stop, Retry, Compact.
- **Ответы на вопросы агента**: варианты и поле для своего ответа показываются в чате.
- **Diff треда** (против базовой ветки, незакоммиченное, pull request) в виде обычного `.diff`-документа.
- **Add Selection to Hoplite Chat**: выделенный код с путём и номерами строк вставляется в поле ввода.
- **Автовыбор проекта** по `git remote` открытой папки.

## Параметры запуска

| Настройка VS Code | В панели чата | Поле API |
| --- | --- | --- |
| `hoplite.model` | список моделей | `model` |
| `hoplite.reasoning` | Reasoning | `reasoning.mode` |
| `hoplite.speed` | Speed | `speed` |
| `hoplite.spendLimitUsd` | ⚙ → Spend limit, USD | `spendLimitMicros` (1 USD = 1 000 000) |
| `hoplite.autoMerge` | ⚙ → Auto-merge pull requests | `autoMerge` |
| `hoplite.repositories` | ⚙ → Repositories and base branches | `repos[]` (`owner/repo` или `owner/repo@branch`) |
| — | ⚙ → Thread title | `title` |
| `hoplite.onBehalfOfUserId` | — | `onBehalfOfUserId` (только сервисные аккаунты) |
| `hoplite.projectId` | кнопка с именем проекта | `projectId` |

Пустое значение означает «по умолчанию»: поле не отправляется, и Hoplite сам подставляет настройку проекта или воркспейса. Уровень reasoning или скорость, которые выбранная модель не поддерживает, не отправляются.

API принимает reasoning, speed, auto-merge и репозитории только при создании треда. В уже открытом треде можно сменить модель для следующих сообщений и лимит расходов.

Прочие настройки:

- `hoplite.apiBaseUrl` — адрес API (по умолчанию `https://api.hoplite.sh`). Задаётся только на уровне пользователя, требует HTTPS (HTTP разрешён только для `localhost`). Ключ отправляется только на этот адрес; перенаправления не выполняются.
- `hoplite.chat.showActivity` — показывать вызовы инструментов, размышления и статусы агента.

## Команды

Все команды доступны в палитре (`Ctrl+Shift+P`) с префиксом `Hoplite:`.

| Команда | Что делает |
| --- | --- |
| Set API Key / Clear API Key | сохранить или удалить ключ |
| Select Project | выбрать проект Hoplite |
| New Thread | начать новый тред |
| Send Prompt… | отправить сообщение без открытия панели |
| Add Selection to Hoplite Chat | вставить выделенный код в поле ввода (есть в контекстном меню редактора) |
| Select Model / Select Reasoning Effort / Select Speed | выбрать параметры запуска |
| Configure Run Parameters | открыть все настройки расширения |
| Stop Run / Retry Last Run / Compact Thread | управление запуском |
| Show Thread Diff / Open Pull Request | результат работы |
| Rename Thread / Set Thread Spend Limit / Archive Thread | управление тредом |
| Refresh / Show Log | обновить данные, открыть журнал |

Команду `hoplite.sendPrompt` можно привязать к клавише, передав текст аргументом.

## Права API-ключа

Расширению нужны: `project:read`, `thread:create`, `thread:read`, `thread:update`, `thread:stop`, `thread:retry`, `modelKey:read`. Личный ключ получает права вашей учётной записи; для сервисного аккаунта выставьте Projects — Read, Threads — Write, Model keys — Read.

Ключ хранится в защищённом хранилище VS Code (SecretStorage). Если ключ не сохранён, используется переменная окружения `HOPLITE_API_KEY`.

## Ограничения

- Агент работает в облачной песочнице Hoplite с репозиторием проекта на GitHub. Локальные незакоммиченные изменения он не видит: передавайте контекст в сообщении или отправляйте изменения в репозиторий.
- Вложения (изображения) не поддерживаются.
- Документация API не описывает, в каком поле кадра `draft` приходит текст черновика. Расширение читает `content` и `text`; если формат окажется другим, ответ появится не по мере набора, а после сохранения сообщения.
- Ответы на несколько вопросов отправляются как `answers` с текстом вопроса в качестве ключа. Это следует из схемы OpenAPI, но явно в документации не описано.
- Проверено в VS Code 1.145.2 с локальным мок-сервером, построенным по OpenAPI-спецификации Hoplite. С реальной учётной записью Hoplite расширение не проверялось.

## Разработка

Нужны Node.js 22.18 или новее и npm.

```bash
npm ci
npm run build      # сборка в dist/
npm run check      # проверка типов и тесты
npm run package    # hoplite-vscode-<версия>.vsix
```

Для отладки откройте папку в VS Code и нажмите `F5` (конфигурация **Run Extension**).

| Путь | Назначение |
| --- | --- |
| `src/api/` | клиент API, разбор потока событий, типы |
| `src/session.ts` | состояние открытого треда: снимок, события, опрос |
| `src/runParams.ts` | сборка запроса на создание треда из параметров |
| `src/controller.ts` | ключ, проект, параметры, действия над тредами |
| `src/views/` | панель чата, дерево тредов, просмотр diff |
| `src/webview/` | интерфейс чата (выполняется в webview) |
| `test/` | тесты на локальном мок-сервере API |
